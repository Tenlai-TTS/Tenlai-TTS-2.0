# Tenlai-TTS 2.0

Audio demonstrations for *Tenlai-TTS 2.0: Continuous-Representation LLM-Based TTS System with End-to-End Training*.

Open `index.html` directly or run `python3 -m http.server 8767 --bind 127.0.0.1` from this directory. The page uses local WAV files and fonts. The sample order, texts and audio pairings are in `samples.js`.
